# 四格散热算例：同样两正两负，误差为什么不同？

下排和上排分别是格 1、2 和格 3、4。横条纹让一排残差为正、另一排为负，棋盘格让相邻两格符号相反。四格的残差绝对值都是 1。这里检验这两种摆法怎样改变散热模型给出的最大误差。[自动生成的报告（PDF）](report.pdf) · [LaTeX 源文件](report.tex)

| 残差排列（下排 / 上排） | 统一上界 | 有符号模态上界 | 精确最大误差 |
| --- | ---: | ---: | ---: |
| 同号 `++ / ++` | 21/4 | 21/4 | 21/4 |
| 横条纹 `++ / --` | 21/4 | 21/46 | 21/46 |
| 棋盘格 `+- / -+` | 21/4 | 21/88 | 21/88 |

棋盘格中每个格子的两名邻居都与它异号，横条纹中只有一名。在固定四格矩阵下，横条纹的最大误差恰为棋盘格的 44/23 倍。基线在棋盘格上比实际误差大 22 倍。结论适用于题面给出的固定矩阵及其离散误差。改变边界和网格后，特征模式需要重新分析。[研究题面](problem.md) · [逐步推导](mode_proof.md)

## 复现实验

在仓库根目录运行下列命令。需要 Python 3，使用标准库，无需模型账号或 LaTeX 环境。

```bash
python MoonshineThermalLab/report_example/verify.py
```

脚本先核对归档、原生技能加载和编译回执，再在临时目录还原原生实验的文件结构。它重新运行 Moonshine 写出的有理数实验，分别比对标准输出和含解向量的 JSON 文件，再用四格特征值核验三项误差。运行不会改写示例文件。[实验代码](mode_check.py) · [原生标准输出](stdout.json) · [完整解向量与回代记录](mode_results.json)
