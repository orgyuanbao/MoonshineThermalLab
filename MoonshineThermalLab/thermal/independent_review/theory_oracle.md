# 外部独立数学 oracle：Robin 导热离散与屏障误差界

本文件由外部独立复核代理在 Moonshine 第 1 阶段运行期间推导，未读取其尚未生成的程序。它不是 Moonshine 自主发现，也不是新的通用误差定理。可作为明确标注来源的后续输入，让 Moonshine 复核、实现并检验适用性。对应代码 `oracle_checks.py` 的真实结果为 `oracle_results.json`。

## 1. 方格单元中心有限体积离散

单位正方形，n×n 网格，Δ=1/n，k>0。T 是相对于固定环境温度的温升，x_i=(i+1/2)Δ、y_j=(j+1/2)Δ。离散方程采用“每个单元的热量平衡”，不除以单元面积。

内部面长度 Δ、两中心距离 Δ，因此导热系数为 k。Robin 边界面中心至单元中心距离 Δ/2。沿法向消去边界面温度 T_f：

    outward integrated flux = k Δ (T_cell − T_f)/(Δ/2) = h_s Δ T_f,
    β_s = Δ/(Δ/(2k)+1/h_s) = kΔ/(k/h_s+Δ/2),
    outward integrated flux = β_s T_cell.

每个边界面向本单元的对角线加 β_s。角单元累加两面；n=1 时唯一单元累加四面，不能只计两面。右端 b_i=∫cell q dA。若用中心值近似源积分，必须声明这是一种有网格依赖的近似；对题面的两个矩形热源，用矩形与单元相交面积积分可使总发热量固定为 0.12。

对于中心采样的原矩形源，n=24 时总发热量为 75/576≈0.1302083333，与 0.12 不同；这本身不等于程序错误，但比较不同网格时不能忽视源离散的变化。

## 2. SPD、单调性和守恒

对任意实向量 v，

    vᵀAv = k Σ内部无向边(i,j) (v_i−v_j)² + Σ边界面(i,s) β_s v_i².

所有项非负。若和为零，连通网格使 v 恒定；至少一个 β_s>0 又使常数为零，因此 A 对称正定。题面所有 h_s≥0.2 自动满足条件。

A 的非对角元非正且连通。若 Av≥0 但 v 有负最小值，最小点的所有差 v_i−v_j≤0，边界项 β_s v_i≤0；该行必须全为等号。沿邻接边传播到有正边界系数的点便矛盾。因此 Av≥0⇒v≥0，A⁻¹逐项非负（离散最大值原理）。

将各单元方程相加，内部边通量相消，得到 Σ边界 β_s T_i = Σ_i b_i。这是守恒校验。b≥0 时最大值原理给出 T≥0。

## 3. 不需要特征值计算的解析屏障

假设 h_s≥h_min>0，定义 f(t)=t(1−t)，

    F_ij = k/h_min + f(x_i)+f(y_j),
    z_ij = F_ij / (4kΔ²).

则对本节精确定义的离散矩阵，逐项有 Az≥1，且 z>0。

证明细节如下：

1. 在完整五点模板中，二次函数 f 的中心二阶差分精确，故 kΣ四邻居(F_ij−F_neighbor)=4kΔ²。
2. 每个缺失的边界外邻居在上述完整模板中贡献恰为 kΔ。例如左面 x=Δ/2 时 f(Δ/2)−f(−Δ/2)=Δ；右面同理。若本单元有 m 个边界面，保留内部邻居后的图 Laplacian 作用为 4kΔ²−m kΔ。
3. 网格中心满足 f(x_i),f(y_j)≥f(Δ/2)=Δ/2−Δ²/4。因此

       F_ij ≥ k/h_min+Δ−Δ²/2
            ≥ k/h_min+Δ/2
            ≥ k/h_s+Δ/2,

   其中第二步使用 0<Δ≤1，第三步使用 h_s≥h_min。
4. 每个边界面由 β_s F_ij≥kΔ 补回被移除的贡献。所以

       (AF)_ij = 4kΔ²−m kΔ + Σ边界面 β_s F_ij ≥4kΔ²,

   除以 4kΔ² 即得 Az≥1。
5. n=1 时 Δ=1，m=4。唯一单元没有内部邻居，4kΔ²−m kΔ=0；F=k/h_min+1/2，四个 β_s F 各自≥k，故论证仍成立。角单元 m=2、一般边单元 m=1、内部单元 m=0 均已包括。

设 T 为离散系统 AT=b 的精确解，近似解为 T̃，残差 r=b−AT̃，c=||r||∞。因为 A(cz±(T−T̃))≥c1−|r|≥0，由单调性可得

    |T−T̃| ≤ c z  （逐项），
    ||T−T̃||∞ ≤ ||r||∞ max_i z_i,
    |max_i T_i − max_i T̃_i| ≤ ||T−T̃||∞.

这是对离散场和离散热点“温度数值”的界，不是热点位置界，也不是连续 PDE 与真实芯片温度的误差界。n=24、k=1、h_min=0.2 时 max z≈791.875，可能较保守；不能预先保证它比原始残差阈值在总成本上更好。

残差计算需要组装或施加 A，必须计入在线成本；解析 z 可预计算，不需要额外完整求解。若系统统一除以 Δ²，需要同步缩放残差和屏障，不能混用两种归一化。

## 4. 一次离线求解的缓存屏障

令 A_min=A(h_min,h_min,h_min,h_min)，精确求解 A_min w=1。由单调性 w>0。β(h) 对 h 单调增加，因此 A(μ)=A_min+D(μ)，D 是非负对角矩阵，A(μ)w≥1。于是也有 |T−T̃|≤||r||∞w。

这通常可能比解析 z 更紧，但需要计入一次离线完整求解、储存和验证 w 的成本。使用浮点近似 w̃ 时，未经验证不可直接称为认证屏障。

如果已可靠证明 δ=||1−A_min w̃||∞<1，则 A_min w̃≥(1−δ)1>0，使 w̃>0；w̃/(1−δ) 成为有效的全参数屏障。参见 Minamihata、Sekine、Ogita、Oishi (2013), Reliable Computing 19:127–141, Theorem 5.1：https://interval.louisiana.edu/reliable-computing-journal/volume-19/reliable-computing-19-pp-127-141.pdf 。该单调矩阵方法属于已有理论；本文的网格表达式与应用实验不能冒称新发明的通用定理。

## 5. 数学上界与浮点认证的区别

上述证明针对精确离散矩阵、精确残差以及精确屏障。ordinary NumPy/SciPy 的浮点残差可能由于消去而偏小，矩阵系数与屏障也有舍入。为了把程序返回的数称为“认证上界”，至少需要：

- 明确被认证的是精确数学离散矩阵，还是已经舍入并存储的矩阵。
- 通过有向舍入、区间算术或可证明的保守舍入包络得到真实残差的上界 c_bar。
- 确保计算的 max z 不小于精确 max z，或者对实际采用的屏障逐项验证 A z≥1。
- 缓存方法中的 δ 同样必须可靠上包络，δ≥1 时应拒绝证书或重新验证。

本 oracle 用 Fraction 对 n=1、2、7、24 的若干有理参数组合逐项检查 Az−1≥0，检查本身在这些组合上是精确的；一般参数结论来自上述代数证明。它没有把普通浮点残差评估伪装成已认证实现。当前数值测试只说明样本上界覆盖误差。

## 6. 独立验证的预期

- 一维常源问题嵌入二维条带，上下绝热、左右正 Robin：连续 T(x)=−qx²/(2k)+ax+b，其中 a=q(1+h_R/(2k))/(k+h_R+h_R k/h_L)、b=ka/h_L。此 FVM 的精确离散中心值为 T(x_i)+qΔ²/(8k)。这给出独立于矩阵重复计算的强校验；该绝热变体仅是验证用例，不是题面的测试参数。
- 光滑二维制造解 T=[1+c x(1−x)][1+c y(1−y)]，所有 h=ck，源项 q=2kc[1+c x(1−x)+1+c y(1−y)]。对源积分精确计算后，用 n=8、16、32、64 比较连续中心值；本次观测的无穷范数误差阶约为 1.980、1.979、1.989。这个结果支持该制造案例的收敛，不是任意不连续源的误差阶证明。
- 小残差大误差的代数例子 A=diag(10⁻⁹,1)、T=(1,0)、T̃=0，残差无穷范数 10⁻⁹ 而场误差为 1。它是 SPD 反例，不应冒称为本热 PDE 的物理反例。
