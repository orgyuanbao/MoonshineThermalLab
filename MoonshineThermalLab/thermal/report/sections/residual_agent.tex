\section{Moonshine 的实际研究与复算}
\paragraph{运行分工。}
本项目基于开源 Moonshine\cite{moonshine} 的研究循环。项目侧给出二维模型、研究问题、误差定义与评价协议，独立准备双端点方案和三网格实验。模型通过本机 Codex 接入，Moonshine 的原生工具负责写入证明、执行程序、返回结果和审核。前期七轮已经建立基础求解器、八维降阶模型和旧自适应策略；本文另启研究会话，保留新题面、原生工具事件、失败与成功证据，各阶段分别记账。

\paragraph{一次可追踪的研究。}
新会话的首轮给出逆非负的 Robin 算子和“利用位置与正负”的目标，允许探索分块，但未提供候选公式或程序。Moonshine 写出证明和有理数检验程序，实际运行时核对了 2592 个小网格样本，其中 1053 个严格紧于标量基准。原生实例包括一个条纹混号四格样本：真实最大误差约为 $0.456522$，标量与无符号块界均为 $5.25$，单端符号界约为 $2.853261$。因此这个例子能单独显示符号信息的贡献。块内混号也可能使极值摘要失去区分度。这里的 2592 是网格、边界和给定残差构造的组合数，小网格上不同命名的构造可能产生同一向量。

\paragraph{程序成功为什么还需复核？}
首轮的程序已经返回成功，但第一次计算审核只收到较短的材料。审核器核对了示例，仍将大批量统计标作证据不足。随后 Moonshine 自行补交脚本与输出，计算审核获得的上下文从 942 个字符增加到 11277 个字符，第二次整体审核通过。这个变化说明，数值程序是否退出成功与审核者是否见到足够的证据可以产生不同结论。两次审核的回执均予以保留。首轮最终记录了 15 个模型回执、一次成功的原生 Python 执行及八条原生归档，项目启动器将该轮判为完成。

\paragraph{第二轮怎样尝试推翻结论？}
在同一会话中，项目方给出式~\eqref{eq:sides-new} 的双端点候选式，请 Moonshine 检查减号方向、构造能严格改进的例子，并寻找不安全捷径的反例，题面没有给出反例向量或结果。它另写 \texttt{moonshine\_interval.py} 并实际调用原生 Python，用精确分数验证了 1968 个参数、残差和分块组合，涉及 13 类检查，其中 328 个组合严格优于第一轮的单端符号界。一个非对称四格条纹例中，最优统一标量界为 $5.25$、单端符号界为 $2.85326$、双端界为 $2.74668$，实际误差为 $0.36230$。这组数说明两次收紧都可能严格，也显示仍有余量。

它还找到了一个与前文独立构造互为镜像的反例：弱端点直接作用于带符号残差给出 $1$，实际误差为 $437/269$。这一发现来自第二轮实际工具输出。该轮记录 10 个模型回执、一次成功的 Python 执行；首次整体验证通过，随后写入五条原生归档。原生小网格脚本的边界顺序在代码中标为左、右、上、下；三网格历史数据按左、右、下、上读取，各用本身的约定。原生小网格、独立穷举和三网格复放属于不同来源，次数不相加作为同一测试的样本量。

\section{复现与来源}
\paragraph{研究产物的归属。}
模型假设、全参数范围、误差阈值以及独立研究问题由项目侧指定。开源 Moonshine 的原版研究循环用于生成、执行和审核原生小网格程序；其底层配置使用 \texttt{gpt-6-astra}。独立验证另行编写四格穷举和固定 16 块的三网格程序，并将原工况复放、每种策略的单独运行、第二条参数流以及图表和论文分开留档。一个原生调用可以进行许多数值检查，本文按真实工具回执和独立程序分别计数。工具日志中的 \texttt{load\_skill\_definition} 表示读取原版已有的研究技能定义。首轮实际读取了直接证明和证明修正等指引，次轮读取了引理证明和反例构造等指引。本项目在启动器中添加了残差研究阶段和题面；上游源码保持核验版本。没有给 Moonshine 增加报告生成技能。原生数学草稿和程序输出归属这两轮研究，课程论文由 Codex 在运行之外按数据编写并用 XeLaTeX 排版，课堂 PPT 与讲稿同样在该流程之外制作。复跑归档的程序无需模型账号，也不产生新的研究轮次。

\paragraph{复现入口。}
进入\href{https://github.com/orgyuanbao/MoonshineThermalLab}{项目仓库}的残差研究目录，以下三个 Python 入口分别对应精确推导、冻结流和新样本。
\begin{itemize}\setlength{\itemsep}{0pt}
\item \texttt{exact\_audit.py} 使用标准库核验四格精确结果。
\item \texttt{run\_experiment.py} 重新执行三网格实验，可逐例比对归档。
\item \texttt{fresh\_stream.py} 在新的 128 个工况上复核五种部署策略。
\end{itemize}
